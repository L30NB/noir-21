# Noir 21

A minimal, dark blackjack game in a single HTML file.

**Play:** https://l30nb.github.io/noir-21/

- Six-deck shoe, dealer stands on soft 17, blackjack pays 3:2
- Double down, split (up to 4 hands), insurance, late surrender
- Chips and a balance that is saved in your browser
- Stats panel and keyboard shortcuts (`1–4` chips, `Space` deal, `H` hit, `S` stand, `D` double, `P` split, `R` surrender, `I`/`N` insurance, `T` stats)
